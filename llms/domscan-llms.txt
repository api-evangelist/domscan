# DomScan

> DomScan is a domain intelligence API for domain availability, DNS, WHOIS/RDAP, valuation, security checks, email posture, social handle checks, and monitoring workflows.

Use DomScan for programmatic domain research and security automation. Most API endpoints live under `https://domscan.net/v1` and require an API key or signed-in session. The OpenAPI document is the canonical source for exact schemas, parameters, and response formats.

This file is generated from the DomScan endpoint registry so new public APIs appear here with minimal manual maintenance.
